Your agent works in a terminal, and you find out what it did by scrolling back. With mdk you look at a board instead. The agent changes status: todo to status: review in a file, and the card crosses the board while you read something else.

How it works

Point mdk at a folder. Point your agent at the same folder.

Any agent that can edit a file can move a card: Claude Code, Codex, Cursor, or a shell script.

Step 1

Add a project

Pick a folder of markdown files. Every .md inside becomes a card. Subfolders become work folders.

Step 2

Write the tasks

Type a card in one line, or ask the agent to break a feature into cards for you.

Fix login p1 #backend @safi due:friday

Step 3

Hand it to the agent

mdk ships an AGENTS.md that teaches the file format. Then one sentence is enough.

Read AGENTS.md and work through the To Do cards.

Step 4

Watch and review

Cards move as the agent saves. Open one to read its notes and ticked subtasks, then drag it to Done.

Questions

Does mdk change my files?

Only the card you edit or move. It never adds config files, hidden folders or IDs to your project. Settings live in your user folder.

Which AI agents work with it?

Any tool that can write a file. The bundled AGENTS.md explains the format, so Claude Code, Codex and Cursor pick it up from one prompt.

Can I keep the cards in Git?

Yes. They are text files, so they diff, merge and commit like the rest of your code.

Is it really free?

Yes. mdk is MIT licensed, with no paid tier and no account. The source is on GitHub.

Does it work with the old MD Kanban?

Yes. mdk reads and writes the same card files as the Electron MD Kanban, so both apps can open the same folder.
